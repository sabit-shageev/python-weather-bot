# 🌤 Weather Bot

Telegram-бот для получения актуальной информации о погоде. Поддерживает текущую погоду, прогноз на 24 часа, кэширование, настройки пользователя и ежедневную рассылку.

---

## 🚀 Возможности

- 📍 **Погода по городу** — текущая температура, ощущения, ветер, влажность.
- 📊 **Прогноз на 24 часа** — с шагом 3 часа.
- 🗂 **Кэширование** — ответы API сохраняются в Redis на 10 минут (погода) и 1 час (прогноз), что снижает нагрузку на внешний сервис и ускоряет ответы.
- 👤 **Пользовательские настройки** — выбор города для ежедневной рассылки.
- ⏰ **Рассылка** — автоматическая отправка погоды каждое утро (время настраивается).
- 🗄 **Постоянное хранение** — данные пользователей, настроек и истории запросов сохраняются в PostgreSQL.
- 🐳 **Контейнеризация** — бот, база данных и кэш запускаются в изолированных Docker-контейнерах.
- 📝 **Логирование** — структурированные логи с уровнями (INFO, WARNING, ERROR, DEBUG) вместо `print`.
- 🧪 **Тестирование** — модульные тесты с покрытием (pytest).
